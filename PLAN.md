# GraphRAG — Implementation Plan

## Objetivo

Implementar 3 features no-críticas en el binario `graphrag`: auto-creación de config por defecto, subcomandos en `init` (db + neovim), y generación de completions para shell.

## Orden de implementación

1. `Cargo.toml` — añadir `clap_complete`
2. `src/config.rs` — `GraphRagConfig::load()` crea el archivo si no existe
3. `src/main.rs` — restructurar `Init`, añadir `Completions`, generar Neovim Lua

### Tarea 2: Auto-crear config por defecto

**Archivos:**
- Modificar: `src/config.rs`

- [ ] **Paso 1:** Añadir método `auto_create_default()` a `GraphRagConfig`
      - Recibe la ruta donde debe escribir (`PathBuf`)
      - Llama a `std::fs::create_dir_all()` sobre el directorio padre
      - Escribe el siguiente contenido TOML con comentarios:

      ```toml
      # GraphRAG Configuration
      # This file was auto-generated by `graphrag`.
      # All fields are optional — CLI flags override these values.

      # Default SQLite database path
      db = "graph.db"

      # Ollama server URL
      ollama_url = "http://localhost:11434"

      # Model used for generating text embeddings
      embed_model = "nomic-embed-text"

      # Model used for named entity recognition (NER)
      ner_model = "llama3.2:3b"

      # Default number of search results
      k = 5

      # Default graph expansion depth
      depth = 2

      # Vector weight in hybrid search (0.0 = pure graph, 1.0 = pure vector)
      alpha = 0.7

      # Base notes directory (used by the Neovim plugin)
      notes_dir = ""
      ```

      Los valores deben coincidir EXACTAMENTE con los defaults de `GraphRagConfig::default()`.

- [ ] **Paso 2:** Modificar `GraphRagConfig::load()`
      Cambiar el `match` actual. Cuando `load_from(&path)` falle con error de tipo `io::ErrorKind::NotFound`:
      1. Loguear con `log::info!("Configuración no encontrada, creando: {}", path.display());`
      2. Llamar a `auto_create_default(&path)`
      3. Llamar a `load_from(&path)` de nuevo (ahora debe funcionar)
      4. Si la segunda carga falla, devolver `Self::default()`

      Cualquier otro error de parseo sigue siendo silencioso → devuelve `Self::default()` como antes.

      Detalles de implementación:
      - Importar `std::io` para poder acceder a `io::ErrorKind::NotFound`
      - El error de `load_from` al ser `anyhow::Result` permite usar `downcast_ref::<io::Error>()`
      - Mantener el log existente `log::info!("Configuración cargada desde: ...")`

- [ ] **Paso 3:** Añadir test unitario `test_auto_create_config`
      ```rust
      #[test]
      fn test_auto_create_config() {
          use tempfile::TempDir;
          let tmp = TempDir::new().unwrap();
          let path = tmp.path().join("graphrag").join("config.toml");
          assert!(!path.exists(), "config should not exist yet");

          // Load from the non-existent path — should auto-create
          let cfg = GraphRagConfig::load_from(&path);
          // First call fails, but we call the auto-create-aware method
          // We test the auto_create_default directly
          GraphRagConfig::auto_create_default(&path).unwrap();
          assert!(path.exists(), "config should have been created");

          // Now load_from should succeed
          let cfg = GraphRagConfig::load_from(&path).unwrap();
          assert_eq!(cfg.db, "graph.db");
          assert_eq!(cfg.ollama_url, "http://localhost:11434");
          assert_eq!(cfg.k, 5);
      }
      ```
      (Este test se añade al módulo `tests` existente en `config.rs`)

- [ ] **Paso 5:** Implementar `cmd_neovim(output: Option<String>) -> Result<()>`
      Añadir esta función:

      ```rust
      fn cmd_neovim(output: Option<String>) -> Result<()> {
          let content = r#"-- GraphRAG Neovim Plugin
-- Auto-generated by `graphrag init neovim`
-- https://github.com/atareao/graphrag

local M = {}

local defaults = {
    db = "graphrag.db",
    bin = "graphrag",
    k = 5,
    depth = 2,
    notes_dir = vim.fn.expand("~"),
}

M.setup = function(opts)
    opts = vim.tbl_deep_extend("force", defaults, opts or {})

    local function run(args)
        local cmd = opts.bin .. " " .. args .. " --db " .. opts.db
        local f = io.popen(cmd, "r")
        if f then
            local result = f:read("*a")
            f:close()
            return result
        end
        return ""
    end

    -- Search related to the current buffer's path
    vim.api.nvim_create_user_command("GraphRagRelated", function()
        local file = vim.fn.expand("%:p")
        local query = vim.fn.input("Related to: ")
        if query == "" then return end
        local result = run("search \"" .. query .. "\" -k " .. opts.k .. " -d " .. opts.depth)
        vim.api.nvim_echo({{result, "Normal"}}, false, {})
    end, { desc = "Search related content" })

    -- Insert related content into current buffer
    vim.api.nvim_create_user_command("GraphRagInsert", function()
        local query = vim.fn.input("Insert related: ")
        if query == "" then return end
        local result = run("search \"" .. query .. "\" -k " .. opts.k .. " -d " .. opts.depth .. " --vector-only")
        local lines = vim.split(result, "\n")
        vim.api.nvim_buf_set_lines(0, vim.fn.line("."), vim.fn.line("."), false, lines)
    end, { desc = "Insert related content" })

    -- Search with flexible query
    vim.api.nvim_create_user_command("GraphRagSearch", function(opts)
        local result = run("search \"" .. opts.args .. "\" -k " .. defaults.k .. " -d " .. defaults.depth)
        vim.api.nvim_echo({{result, "Normal"}}, false, {})
    end, { nargs = 1, desc = "Search graph" })

    -- Full-text search
    vim.api.nvim_create_user_command("GraphRagFts", function(opts)
        local result = run("fts \"" .. opts.args .. "\"")
        vim.api.nvim_echo({{result, "Normal"}}, false, {})
    end, { nargs = 1, desc = "Full-text search" })

    -- Find shortest path between two nodes
    vim.api.nvim_create_user_command("GraphRagPath", function()
        local from = vim.fn.input("From: ")
        if from == "" then return end
        local to = vim.fn.input("To: ")
        if to == "" then return end
        local result = run("path \"" .. from .. "\" \"" .. to .. "\"")
        vim.api.nvim_echo({{result, "Normal"}}, false, {})
    end, { desc = "Shortest path" })

    -- Show database stats
    vim.api.nvim_create_user_command("GraphRagStats", function()
        local result = run("stats")
        vim.api.nvim_echo({{result, "Normal"}}, false, {})
    end, { desc = "Graph statistics" })

    -- Keymaps
    vim.keymap.set("n", ",gr", function()
        local file = vim.fn.expand("%:p")
        local result = run("related " .. file .. " -k " .. defaults.k)
        vim.api.nvim_echo({{result, "Normal"}}, false, {})
    end, { desc = "GraphRAG related" })

    vim.keymap.set("n", ",gi", function()
        local query = vim.fn.input("Insert related: ")
        if query == "" then return end
        local result = run("search \"" .. query .. "\" -k " .. defaults.k .. " -d " .. defaults.depth .. " --vector-only")
        local lines = vim.split(result, "\n")
        vim.api.nvim_buf_set_lines(0, vim.fn.line("."), vim.fn.line("."), false, lines)
    end, { desc = "GraphRAG insert" })
end

return M
"#;

          match output {
              Some(path) => {
                  std::fs::write(&path, content)?;
                  println!("✅ Plugin Neovim generado: {}", path);
              }
              None => {
                  println!("{}", content);
              }
          }

          Ok(())
      }
      ```

- [ ] **Paso 6:** Implementar `cmd_completions(shell: Shell) -> Result<()>`
      Añadir esta función:

      ```rust
      fn cmd_completions(shell: Shell) -> Result<()> {
          let mut cmd = Cli::command();
          let name = cmd.get_name().to_string();
          clap_complete::generate(shell, &mut cmd, name, &mut std::io::stdout());
          Ok(())
      }
      ```

      Nota: `Cli::command()` viene del derive de clap. La función necesita acceso a `Cli`, que está definida en el mismo ámbito. Como `cmd_completions` se define después de `main()`, no hay problema de orden.
